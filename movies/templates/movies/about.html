ABOUT CINEBOOK

Movie night, made simple.

CineBook is a demonstration movie catalogue, review and seat reservation project. Theatre and showtime records marked DEMO are sample data, not real cinema listings.

Optional TMDB integration

TMDB

CineBook does not call TMDB automatically. The integration is optional and only runs when an administrator explicitly starts the artwork importer. If TMDB data is used, display this disclaimer: “This product uses the TMDB API but is not endorsed or certified by TMDB.”

Imported artwork and catalogue ratings must be sourced and used according to TMDB's terms and applicable rights. Until configured, CineBook uses local fallback artwork or administrator-entered image URLs.
